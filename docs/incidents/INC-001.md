## 3. Виконані дії й тимчасовий обхід

1. Перевірка доступності: `/api/health` 200 — це не відмова інфраструктури, RB-001 не застосовується.
2. Звірка залишків поставки з позиціями (`delivery_items.ordered_quantity`) — знайдено подвійне застосування.
3. Обхід: `UPDATE products SET quantity_in_stock = quantity_in_stock - <надлишок> WHERE product_id = ... AND
   quantity_in_stock = <хибне значення>`. Умова не дає «виправити» товар, який хтось уже встиг продати.
4. Заборона на повторне натискання «Прийняти» (усна) до виправлення коду — обхід процесом, а не системою.

[Post-Mortem](postmortem-INC-001.md).
