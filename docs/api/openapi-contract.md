# Контракт OpenAPI

Довідка нижче **не копіює** специфікацію: під час збирання сайту плагін `swagger-ui-tag` вбудовує файл
[`openapi.yaml`](openapi.yaml) як є. Зміна контракту = нова довідка після наступної збірки; розійтися вони не можуть.
Кнопка «Try it out» тут показує запит, а виконується він у працюючому екземплярі на <http://localhost:5000/api/docs>
(той самий домен, тож працюють і сесійні cookie).
